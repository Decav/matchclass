# Estándar de Idioma — Copy de UI en MatchClass

**Regla:** todo texto de interfaz (botones, mensajes de error, títulos, subtítulos, placeholders, links) se escribe en español neutro, forma "tú". Nada de voseo rioplatense (formas con "vos").

**Aplica a:**
- Texto en los frames de `matchclass_design.pen`
- Mensajes de error, validación y feedback en la app
- Labels, placeholders, botones

## Ejemplos de corrección

| Voseo (evitar) | Neutro (usar) |
|---|---|
| "Ingresá un email válido" | "Ingresa un email válido" |
| "Intentá de nuevo" | "Intenta de nuevo" |
| "Revisá con tu ayudante" | "Revisa con tu ayudante" |
| "Completá tus datos" | "Completa tus datos" |
| "Creá tu cuenta" | "Crea tu cuenta" |
| "Iniciá sesión" | "Inicia sesión" |
| "Ingresá el código" | "Ingresa el código" |
